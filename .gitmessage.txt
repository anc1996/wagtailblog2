# <类型>(<可选模块>): <中文动词 + 业务改动内容>
#
# 常见类型：
#   feat:     新增功能
#   fix:      缺陷修复
#   docs:     文档或说明书变更
#   style:    代码格式调整（不影响业务逻辑）
#   refactor: 代码重构（非新增功能亦非修复bug）
#   perf:     性能优化
#   test:     测试用例新增或调整
#   chore:    构建流程、辅助工具或依赖变动
#
# 提交示例：
#   docs(specs): 规范Git提交信息必须使用中文
#   feat(blog): 新增博客分类多级筛选支持
#
# 【强制要求】：冒号后必须为中文，严禁纯英文提交说明！
