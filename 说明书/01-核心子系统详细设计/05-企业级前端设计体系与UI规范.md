# 05-企业级前端设计体系与UI规范实现说明书

> **文档版本**：v1.1.0
> **文档定位**：前端设计体系与企业级 UI 规范落地实现与交付说明书（从设计方案转为工程落地实现规范，杜绝冗余讨论）
> **架构师**：gpt-5.6-sol（高推理）

## 1. 视觉定位与核心设计母题

本系统定位于“**高品质中文知识库式编辑出版平台**”，服务技术文档、公文材料、理论学习与架构沉淀。

视觉母题坚持**理性编辑型的瑞士平面风格（Swiss Minimalism）**：
- **高可读性**：正文清晰规整，文字行高、字距与段间距遵循出版级排版黄金比例。
- **克制装饰**：剔除营销型大图弹窗、浮夸玻璃拟态与不必要的渐变动画，突出内容本位。
- **阅读优先**：核心正文宽度收敛于 780px 舒适阅读区，辅助栏目低对比度弱化，降低认知负荷。
- **无缝主题切换**：原生适配亮色模式（暖灰/米白底）与深色模式（沉浸黑底），杜绝刺眼突变。

## 2. 六层前端架构体系

系统遵循清晰的分层解耦规范，杜绝全局样式随意覆盖与 CSS 硬编码：

| 架构层级 | 职责范围 | 落点文件与约定 |
| :--- | :--- | :--- |
| **Layer 1: Foundation** | 语义 CSS Token、调色板、字体栈、间距基数、动画曲线 | `static/css/site-theme.css`；严禁在业务组件中新增 raw hex 色值 |
| **Layer 2: Shell** | 全局头部 Header、主导航、页脚 Footer、容器宽度与 Skip Link | `templates/includes/header.html`、`footer.html`；桌面与移动端共享焦点管理 |
| **Layer 3: Primitives** | 基础原子组件：按钮、标签 Tag、卡片、输入框、徽章、状态指示器 | 从首页、文章与专栏中抽象通用类名，不引入庞大外部 UI 库 |
| **Layer 4: Content** | 内容块渲染：Markdown 标题、代码高亮、Mermaid 图表、KaTeX 公式、画廊 | `static/content/` 与 `templates/includes/content/`；适配亮暗双色与按需加载 |
| **Layer 5: Page** | 页面级组合：首页、专栏索引页、文章详情页、作者页、标签归档页 | 仅负责装配 Primitives 与 Content，消除页面级冗余 CSS |
| **Layer 6: Behavior** | 交互行为逻辑：主题切换、导航展开、搜索局部刷新、画廊异步分批加载 | 优先使用原生 ES 模块；jQuery 仅作为特定遗留组件的局部隔离孤岛 |

## 3. 语义化 CSS Token 体系 (`site-theme.css`)

统一通过 CSS 变量暴露语义 Token，实现全局亮/暗主题一键自适应：

```css
:root {
  /* 品牌色系：经典暖棕与沉稳焦糖 */
  --site-primary: #8c5b3f;
  --site-primary-hover: #70442c;
  --site-accent: #2e7d6b; /* 青绿焦点辅助色 */

  /* 亮色模式阅读表面 */
  --site-bg: #fbfbfa;
  --site-surface: #ffffff;
  --site-text: #2c2c2a;
  --site-text-muted: #6b6b66;
  --site-border: #e8e8e3;

  /* 排版尺寸 */
  --site-reading-width: 780px;
  --site-line-height: 1.85;
}

[data-theme="dark"] {
  /* 深色模式沉浸表面 */
  --site-bg: #141413;
  --site-surface: #1e1e1c;
  --site-text: #e6e6e1;
  --site-text-muted: #9e9e96;
  --site-border: #2e2e2a;
}
```

## 4. 关键页面与核心内容块排版规范

### 4.1 文章详情页黄金排版

- **宽度与行距**：正文容器固定 `--site-reading-width: 780px`，字体大小 17px，行高 1.85，中英文混合自动断词。
- **标题层级与间距**：
  - 一级标题（文章名）：32px 粗体，底边距 24px。
  - 二级标题（`##`）：24px 粗体，上边距 40px，下边距 16px（解决紧贴上一段文字的视觉压迫）。
  - 三级标题（`###`）：19px 粗体，上边距 28px，下边距 12px。

### 4.2 技术与富内容块适配

- **代码高亮块**（Highlight.js）：亮暗主题自动匹配，带语言标识，代码字体统一采用 Fira Code / JetBrains Mono，支持横向平滑滚动与行号对齐。
- **流程图块**（Mermaid）：全站统一升级 Mermaid v11.12 ESM 现代渲染引擎，支持响应式居中自适应与暗色图表高对比度。
- **数学公式块**（KaTeX）：本地离线字体渲染，零外部 CDN 依赖，支持公式过长时局部滑动。
- **图片与画廊**：
  - 文章内单张图片（`image_block`）：自适应屏幕，半宽图片自动居中，带有优雅圆角与图注。
  - 图片画廊（`gallery_block`）：采用**统一画布高度**方案，消除不同尺寸原图参差不齐的塌陷；实现响应式 4 列网格自适应；大批量图片支持 **AJAX 分批加载**，彻底杜绝首屏卡顿。

### 4.3 专栏索引与文章卡片信息流

- 彻底解耦封面图比例与正文摘要流，针对无图文章自动采用优雅的纯文本紧凑卡片，修复作者页与搜索页卡片高度塌陷或留白过大的历史缺陷。

## 5. 可访问性与工程质量门禁 (WCAG 2.1 AA)

1. **色彩对比度**：正文文字与背景色对比度达到 7:1 以上，次级文字达到 4.5:1，深色与浅色双模式均达标。
2. **全站键盘导航**：
   - 页面顶部内置 `Skip to main content` 跳转锚点。
   - 所有可聚焦元素（链接、按钮、输入框）均具备鲜明的焦点高亮环（Focus Ring），不得随意使用 `outline: none`。
3. **移动端触控优化**：
   - 按钮与交互区域最小触控尺寸不低于 44×44px。
   - 移动端视口（375px~430px）严格杜绝任何页面级横向非必要滚动条。

## 7. 验证与交付结论

- **多端视口实测通过**：使用 Playwright 与真实浏览器对 375px（iPhone SE）、390px（iPhone 14）、768px（iPad）与 1440px（MacBook/PC）进行多轮验收，界面整洁利落，动效轻盈。
- **静态资源合规**：全站静态文件已通过生产 `collectstatic` 构建优化，无遗留死链或 404 资源。
