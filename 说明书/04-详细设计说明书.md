# WagtailBlog3 详细设计与代码维护手册

## 1. Blog 模块

主文件 `apps/blog/models.py`：452 行起为 `BlogPage`；285 行起为 `BlogPageForm`；723 行 `save()` 写 Mongo；795 行 `publish()`，800 行 `unpublish()`，808 行 `delete()`；939 行 `get_context()`，947 行 `serve()`；981 行 `get_full_text_for_search()`。修改正文结构时必须同时检查 `apps/blog/blocks.py`、`mongodb.py`、`mongo.py`、对应模板和 Markdown 兼容测试。

`BlogIndexPage.get_listing_context()` 负责搜索、日期范围、排序和分页；`services/feed_query.py`、`tag_listing.py`、`content_analytics.py` 提供可复用查询。列表查询应延续 `select_related/prefetch_related/defer` 约定，避免重新读取大正文。

## 3. 修改规则

改变搜索字段先改 `document.py` 和 `content_index.py` mapping，再增加索引版本和重建流程；改变公开边界必须同时改 `pages_query.py`、一致性测试和删除语义；改变 cursor schema 必须递增版本并保留旧 token 的明确错误。

## 4. 运维命令定位

`search_sync_status` 看状态，`search_consistency_check` 查差异，`search_rebuild_content_index` 重建，`search_switch_content_alias` 切换，`search_rollback_content_alias` 回滚，`search_replay_delivery` 重放事件，`search_bootstrap_state` 初始化状态；生产专用命令必须使用名称中带 `production` 的命令并通过确认参数。
