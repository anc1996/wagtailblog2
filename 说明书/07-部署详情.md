# WagtailBlog3 部署详情与现场核查表

## 1. 组件

应用依赖 MySQL、MongoDB、Redis、MinIO、Elasticsearch、Nginx、uWSGI、Celery/Beat 和 Filebeat。Django 配置集中在 `settings/base.py`、`settings/database.py`、`settings/logging.py`、`settings/dev.py`；生产实际值只从 `.env.production` 和 systemd unit 读取。

## 2. 部署前必须记录

`hostname`、项目绝对路径、分支、完整 SHA、remote URL、Conda Python、Nginx 监听端口、uWSGI socket、四个 unit 的 `FragmentPath/EnvironmentFile/ExecStart`、数据库/Redis/Mongo/ES 健康状态、当前 content read alias 和备份位置。

## 3. 变更影响矩阵

| 变更 | 需重启 | 需迁移/数据门禁 |
|---|---|---|
| Python/模板/静态 | 网站；Worker/Beat 受影响时同步 | 否 |
| 模型/迁移 | 网站及任务按影响 | 是，先备份 |
| Celery task/队列 | Worker、Beat | 否 |
| ES mapping/alias | 相关命令或服务 | 是，备份+回滚 |
| systemd/env | daemon-reload、受影响服务 | 视配置而定 |

不得使用 `rsync --delete`、未知工作树上的 `git pull`、`docker compose down -v` 或批量删除索引。
