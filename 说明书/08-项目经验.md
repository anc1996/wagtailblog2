# WagtailBlog3 维护经验与编码规约

1. 先找入口再改实现：URL → view → service → model/外部系统 → template/task；不要仅凭文件名重构。
2. Wagtail Page 的 `save/publish/unpublish/delete` 是生命周期边界；业务副作用用 signal/service，避免循环调用。
3. StreamField 是序列化协议。block type、字段名、Markdown key 变更必须有兼容迁移和历史数据测试。
4. 大正文查询默认 `defer("body", "mongo_content_id")`，列表不要逐页读取 Mongo。
5. Outbox 是可靠状态，Celery 只是唤醒；broker 丢消息由 Beat 补偿，不可把“任务已入队”当作完成。
6. 错误日志记录 code 和截断摘要，不记录正文、密码、Token、完整请求头。
7. 所有 production 命令先 dry-run，再确认参数、备份引用、目标 alias 和回滚点。
