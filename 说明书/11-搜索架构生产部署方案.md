# 内容搜索生产部署方案

## 1. 适用代码

生产专用命令位于 `apps/search/management/commands/`：创建索引、重建、切 alias、回滚、状态、一致性、重放 Delivery、退休 Target。先阅读命令参数和 dry-run 输出，不得把测试命令改环境变量后当生产命令使用。

## 2. 执行顺序

1. 核对目标 SHA、生产工作树、MySQL/Mongo/Redis/ES、备份引用和 `.env.production`。
2. 创建禁用的 production Target/building index，验证 template/mapping。
3. 运行 bootstrap/rebuild，保存 checkpoint 和报告；观察 Mongo、ES bulk、MySQL 锁和 maintenance 队列。
4. 追平 Outbox/Delivery，运行 consistency check，抽样核对公开页面、标题、日期、摘要和删除墓碑。
5. 使用 `search_switch_production_content_alias` 原子切换 read alias；观察查询 5xx、延迟、dead/retry。
6. 仅在单独授权后启用 production rebuild/query/producer/consumer flags。

## 3. 回滚

查询异常先执行 alias rollback；同步异常暂停 consumer、保留事件和索引证据；代码异常恢复上一已验证 SHA。不得删除 Mongo 正文、草稿或 revision；迁移只在兼容性已确认时处理。
