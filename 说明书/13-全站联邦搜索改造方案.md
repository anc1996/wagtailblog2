# 全站联邦搜索代码说明与扩展规约

## 1. 当前实现

`services/federated_query.py` 将独立 Blog 内容结果与 `pages_query.py` 的公开 Wagtail Page 结果合并；候选数由 `FEDERATED_CANDIDATE_LIMIT` 控制，使用稳定排序和签名 federated cursor。`search_type=blog` 可直接使用内容索引；`all` 走联邦合并。本文不宣称所有 Page 类型已接入内容索引。

## 2. 新 provider 接入

必须实现统一的 query、count、排序、highlight、cursor、超时和降级契约；定义公开过滤、日期字段、URL/title 摘要映射、删除语义和测试 fixture。provider 故障应记录可观测错误并允许其他 provider 返回。

## 3. 不得破坏的契约

公开边界二次校验、结果稳定顺序、分页 token 版本、`search_unavailable` 错误码和不泄露内部字段的 API schema。任何 provider 扩展都要增加单元、集成和浏览器测试。
