# 搜索旧流程退役与代码精简规约

## 1. 现行保留链路

保留 `signals.py` → `outbox.py` → `delivery.py` → `tasks.py` → `elasticsearch.py`，以及 `rebuild.py`、`alias.py`、`consistency.py`、cursor、suggestions 和生产管理命令。这些模块共同保证事务事实、至少一次投递、可恢复重建和可回滚读切换。

## 2. 退役判定

任何旧实现必须先完成 `rg` 调用图、运行日志、测试覆盖和配置引用核对；确认没有 URL、signal、task、模板、management command 或 systemd unit 使用后，才能删除。删除前补等价测试、迁移说明、回滚 commit 和生产索引影响评估。

## 3. 禁止误删

不得删除 `BlogPage` 正文/历史、Mongo 指针、Wagtail revision、Outbox/Delivery 记录、SearchIndexBuild checkpoint、ES snapshot 或仍被 default Wagtail 搜索使用的代码。
