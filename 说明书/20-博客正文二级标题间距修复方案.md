# 博客正文二级标题间距修复方案（维护摘要）

## 目标

收紧博客正文 `h2` 与后续内容的垂直间距，避免 GitHub Markdown 默认样式造成大段空白；不改变 Markdown、StreamField、模板结构或标题层级。

## 实现

- 入口样式：`wagtailblog3/static/css/site-theme.css`。
- 作用域：`.blog-page-wrapper .article-body-content h2`，`margin-top: 1.5rem`、`margin-bottom: 0.65rem`；其他页面和标题级别不受影响。
- `wagtailblog3/templates/base.html` 更新静态资源版本参数，确保浏览器加载新样式。

## 验收与回滚

运行 `python manage.py check`、`git diff --check`，并在桌面与 390px 移动视口检查无横向溢出、锚点可用和 h1/h2/h3 间距。回滚时恢复上述 CSS 规则及静态版本参数；不涉及数据库、MongoDB、媒体或服务配置。

## 实施记录

2026-08-20 完成两轮调整，最终实测 h2 上间距 24px、下间距约 10.4px；桌面/移动验收通过，未提交生产数据操作。后续若修改主题间距，只需更新本文件和对应 CSS 验收记录。
