# 前端设计体系与全站 UI 美化演进摘要

> **归档收敛说明**：本篇由历史原始文档 `20-博客正文二级标题间距修复方案.md`、`23-博客全站优化路线与实施计划.md` 及 `26-前端统一美化与企业级设计体系方案.md` 提炼收敛而成。剔除早期大量关于微调像素、临时 CSS 试错的过程记录，系统性保留企业级六层前端设计架构、瑞士平面排版规范及排版体验修复的关键决策。

---

## 1. 早期前端痛点与全站优化路线 (原 23)

- **早期界面缺陷**：
  - CSS 样式分散在各个 HTML 模板与组件内，缺乏全局 Design Tokens，维护成本极高。
  - 移动端适配粗糙，小屏幕设备（< 375px）频繁出现横向滚动条、正文超宽以及菜单遮挡问题。
  - 暗黑模式（Dark Mode）色彩对比度不达标，文字可读性差，未满足无障碍标准。
- **治理目标**：确立“少即是多”的现代工程化设计理念，引入瑞士平面设计风格，建立分层 CSS 体系，全面提升阅读体验与无障碍合规性。

---

## 2. 企业级六层前端架构体系 (原 26)

重构后确立了清晰的六层前端资产组织体系，消除了样式覆盖冲突：

```
[Layer 1: Foundation (设计变量/Tokens)]  --> CSS Reset, 色彩变量, 间距标尺
[Layer 2: Typography (瑞士排版体系)]   --> 字体搭配, 行高律动, 字阶比例
[Layer 3: Layouts (栅格与容器)]        --> 780px 黄金阅读宽度, 响应式断点
[Layer 4: Components (原子组件)]      --> 文章卡片, 标签, 模态框, 搜索抽屉
[Layer 5: Utilities (功能辅助类)]     --> 屏幕阅读器文本, 键盘焦点增强
[Layer 6: Behavior (交互与动效)]      --> 主题切换, 目录滚动监听, 移动端抽屉
```

### 2.1 瑞士排版哲学与字体系统
- **排版原则**：追求清晰、客观、数学律动，强化负空间（留白）的呼吸感。
- **字体族序列**：
  - 西文字体：优先调用 `Inter`, `-apple-system`, `BlinkMacSystemFont`。
  - 中文字体：优选 `PingFang SC`, `Microsoft YaHei`，正文行高锁定为 `1.75`，字符间距微调为 `0.01em`。
  - 代码高亮：指定等宽字体 `JetBrains Mono`, `Fira Code`。

### 2.2 780px 黄金阅读容器与留白
- 长文阅读体验由页面容器宽度决定：过宽易造成视线折返疲劳，过窄则破坏代码块与长表格的排版。
- 文章详情页主体宽度被严格锁定为 **`780px`（最大不超过 840px）**，配合右侧悬浮式目录导航（TOC），实现沉浸式深度阅读体验。

## 3. 典型体验缺陷修复：正文二级标题（H2）垂直韵律 (原 20)

- **缺陷现象**：博客正文中的二级标题（`<h2>`）在紧随图片、引用块或代码块时，由于 CSS 默认外边距折叠或不一致，经常出现与上方内容紧贴、与下方正文过散的严重失衡。
- **根因治理**：
  在 Layer 2 排版层建立严格的标题间距规约，消除局部 inline hack：
  ```css
  .blog-content h2 {
    margin-top: 2.75rem;    /* 与上方前置内容拉开明显视觉分块 */
    margin-bottom: 1.125rem; /* 与下方说明正文保持紧凑关联 */
    padding-bottom: 0.5rem;
    border-bottom: 1px solid var(--color-border-subtle);
    font-size: 1.625rem;
    font-weight: 700;
    line-height: 1.35;
  }
  ```

## 4. 无障碍标准（WCAG 2.1 AA）与主题自适应 (原 23, 26)

1. **色彩对比度达标**：
   - 浅色模式与深色模式下，正文与背景对比度均 `>= 4.5:1`，大标题对比度 `>= 3:1`。
   - 严禁仅靠颜色传递状态（如错误提示必须同时具备图标和文本说明）。
2. **键盘导航与焦点可见性**：
   - 全局交互元素（按钮、链接、输入框）配置了显式的 `:focus-visible` 轮廓光环（Focus Ring），无障碍辅助设备可无障碍漫游。
3. **移动端绝对无横向溢出**：
   - 所有表格强制包裹滚动容器，大图配置 `max-width: 100%; height: auto;`，彻底杜绝小屏溢出。
