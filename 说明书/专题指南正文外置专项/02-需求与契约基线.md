# 专题指南正文外置需求与契约基线

> 版本：1.0｜日期：2026-10-05｜本文件是专项需求的精简事实源

## 1. 业务需求

GuidePage 使用 Wagtail 页面承载标题、层级、权限和发布状态；正文 `body` 外置到 MongoDB。用户必须能安全完成：

- 后台创建、保存草稿、预览、编辑和历史恢复。
- 审批/发布、取消发布、定时发布和失败重试。
- 单页复制、递归复制、别名、别名转换。
- 删除、批量删除、删除意图取消、恢复和安全清理。
- 前台访问、缺失正文降级、搜索分类隔离。

## 2. 数据契约

- MySQL 是页面、Revision、正式发布指针和生命周期意图的权威来源。
- MongoDB 保存不可变正文版本；正文以原始 Markdown 字符串落盘。
- `markdown_block` 存储 key 稳定，HTML 只在模板渲染阶段生成。
- 正式指针必须能映射到 Mongo `version_id`，且校验 page、field、generation、sha256 等身份字段。
- MySQL 事务提交前不能把页面标记为正式发布；Mongo 写入失败必须 Fail-Closed。
- Outbox 与业务事务同批写入 MySQL，Elasticsearch 由异步消费者投影，不假定同步完成。
- 删除必须经过删除意图、引用复核、安全期和租约围栏；禁止裸删除绕过生命周期。

## 3. 不变量

1. 草稿正文、正式正文、Revision pointer 和 `mongo_content_id` 不静默互指。
2. 已发布版本不可被后续草稿覆盖。
3. 复制/别名遵循当前不可变发布 Manifest 语义，不预设立即生成独立 Mongo 副本。
4. 任何缺正文、哈希不匹配、指针悬挂、锁冲突或未取消删除意图均阻断写入或发布。
5. 读路径在正文缺失时返回受控错误，不返回伪造空正文。

## 4. 验收对象

| 对象 | 必须核验 |
|---|---|
| 创建/草稿 | MySQL Revision、Mongo 版本、哈希和正文原文 |
| 发布/取消发布 | 正式指针、generation、Mongo 发布态、Outbox |
| 复制/别名 | source-target 映射、Manifest、独立修改隔离 |
| 删除/恢复 | intent 状态、层级锁、引用、安全期、恢复后正文 |
| 搜索 | `guides/pages/blog/all` 分类、权限、投影延迟 |
| 异常 | Mongo 不可用、MySQL 失败、重复回调、并发冲突、缺正文 |
