# 搜索流程运行手册

## 1. 公开查询

请求进入 `search/views.py` 或 `search/api.py` → 清理 query/日期/排序 → `core.perform_search()` 或 `services/content_query.py` → ES serving alias 查询 → MySQL `live().public()` 按 page id、语言和公开状态二次过滤 → 构造摘要/高亮 → 返回 HTML/JSON。`all` 由 `federated_query.py` 合并，建议由 `suggestions.py` 提供。

## 2. 内容变更

Wagtail 发布/取消发布/删除 → `apps/search/signals.py` → MySQL 事务写 `ContentSearchState` + `ContentSearchOutbox` → 物化 `ContentSearchDelivery` → maintenance Worker 领取租约 → 读取 Mongo 正式正文和最新状态 → ES upsert/tombstone → 完成 Delivery；失败按退避重试，Beat 扫描补偿。

## 3. 重建与切换

创建 building Target → `search_rebuild_content_index` 分批回填并保存 checkpoint → catch-up 追平事件 → `search_consistency_check` → `search_switch_content_alias` → 观察 → 必要时 `search_rollback_content_alias`。任何阶段都不得用空正文覆盖或删除旧 serving 索引。

## 4. 排障顺序

先查 HTTP 状态和应用日志，再查 serving alias/Target，再查 Outbox/Delivery 状态和租约，随后查 Mongo 正文读取和 ES bulk/cluster，最后检查 Redis、Worker、Beat。使用 `search_sync_status`、`search_consistency_check` 和 `search_replay_delivery`，所有生产写命令先 dry-run 并确认。
